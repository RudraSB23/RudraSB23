## 🚀 Current Projects

- 💾 **Pendrive AI** — A fully portable USB-native Windows Batch script that dynamically detects host hardware to run a local `llama.cpp` server. Features a CLI menu, multimodal auto-routing, vision model support, and built-in MCP proxy hooks.
- 🔌 **Hardware-in-the-Loop AI** — Model Context Protocol (MCP) setups via Cloudflare tunnels allowing cloud LLMs to control physical IoT hardware via NodeMCU.
- 🧠 **[rag](https://github.com/RudraSB23/rag)** — Lightweight Retrieval-Augmented Generation application for local PDF querying using local models.
- ⚙️ **[fotd-engine](https://github.com/RudraSB23/fotd-engine)** — A custom game engine built from scratch in Python.

## 📦 Legacy & Side Projects

Things I build while experimenting. Some might still be useful:
